An axis-aligned rectangle is represented as a list  `[x1, y1, x2, y2]`, where  `(x1, y1)`  is the coordinate of its bottom-left corner, and  `(x2, y2)`  is the coordinate of its top-right corner. Its top and bottom edges are parallel to the X-axis, and its left and right edges are parallel to the Y-axis.

Two rectangles overlap if the area of their intersection is  **positive**. To be clear, two rectangles that only touch at the corner or edges do not overlap.

Given two axis-aligned rectangles  `rec1`  and  `rec2`, return  `true` _if they overlap, otherwise return_ `false`.

**Example 1:**
```
Input: rec1 = [0,0,2,2], rec2 = [1,1,3,3]
Output: true
```

**Example 2:**
```
Input: rec1 = [0,0,1,1], rec2 = [1,0,2,1]
Output: false
```

**Example 3:**
```
Input: rec1 = [0,0,1,1], rec2 = [2,2,3,3]
Output: false
```

**Constraints:**

-   `rec1.length == 4`
-   `rec2.length == 4`
-   `-109 <= rec1[i], rec2[i] <= 109`
-   `rec1`  and  `rec2`  represent a valid rectangle with a non-zero area.


### Python
```py
class Solution:
    def isRectangleOverlap(self, rec1: List[int], rec2: List[int]) -> bool:
        rec_1x, rec_2x = sorted([[rec1[0], rec1[2]], [rec2[0], rec2[2]]])
        rec_y1, rec_2y = sorted([[rec1[1], rec1[3]], [rec2[1], rec2[3]]])
        r1x1, r1x2 = rec_1x[0], rec_1x[1]
        r2x1, r2x2 = rec_2x[0], rec_2x[1]
        r1y1, r1y2 = rec_y1[0], rec_y1[1]
        r2y1, r2y2 = rec_2y[0], rec_2y[1]
        return max(r1x1, r1x2) > min(r2x1, r2x2) and max(r1y1, r1y2) > min(r2y1, r2y2)
```

```go
func isRectangleOverlap(rec1 []int, rec2 []int) bool {
    r1x_low, r1x_high := rec1[0], rec1[2]
	r2x_low, r2x_high := rec2[0], rec2[2]
	rec_1x := []int{r1x_low, r1x_high}
	rec_2x := []int{r2x_low, r2x_high}
    
	if rec_1x[0] > rec_2x[0] {
		rec_1x, rec_2x = rec_2x, rec_1x
	}

	r1y_low, r1y_high := rec1[1], rec1[3]
	r2y_low, r2y_high := rec2[1], rec2[3]
	rec_y1 := []int{r1y_low, r1y_high}
	rec_2y := []int{r2y_low, r2y_high}

	if rec_y1[0] > rec_2y[0] {
		rec_y1, rec_2y = rec_2y, rec_y1
	}

	r1x1, r1x2 := rec_1x[0], rec_1x[1]
	r2x1, r2x2 := rec_2x[0], rec_2x[1]
	r1y1, r1y2 := rec_y1[0], rec_y1[1]
	r2y1, r2y2 := rec_2y[0], rec_2y[1]
	xMatch := math.Max(float64(r1x1), float64(r1x2)) > math.Min(float64(r2x1), float64(r2x2))
	yMatch := math.Max(float64(r1y1), float64(r1y2)) > math.Min(float64(r2y1), float64(r2y2))
	return xMatch && yMatch
}
```

```c#
public class Solution {
    public bool IsRectangleOverlap(int[] rec1, int[] rec2) {
        int[] itemX1 = new int[] { rec1[0], rec1[2] };
        int[] itemX2 = new int[] { rec2[0], rec2[2] };
        int[] rec_1x = itemX1[0] <= itemX2[0] ? itemX1 : itemX2;
        int[] rec_2x = itemX1[0] <= itemX2[0] ? itemX2 : itemX1;

        int[] itemY1 = new int[] { rec1[1], rec1[3] };
        int[] itemY2 = new int[] { rec2[1], rec2[3] };
        int[] rec_y1 = itemY1[0] <= itemY2[0] ? itemY1 : itemY2;
        int[] rec_2y = itemY1[0] <= itemY2[0] ? itemY2 : itemY1;

        int r1x1 = rec_1x[0], r1x2 = rec_1x[1];
        int r2x1 = rec_2x[0], r2x2 = rec_2x[1];
        int r1y1 = rec_y1[0], r1y2 = rec_y1[1];
        int r2y1 = rec_2y[0], r2y2 = rec_2y[1];

        bool xMatch = Math.Max(r1x1, r1x2) > Math.Min(r2x1, r2x2);
        bool yMatch = Math.Max(r1y1, r1y2) > Math.Min(r2y1, r2y2);
        return xMatch && yMatch;
    }
}
```
