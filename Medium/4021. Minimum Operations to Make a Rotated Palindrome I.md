You are given a string  `s`  consisting of lowercase English letters.

You can perform the following operations any number of times (including zero) and in any order:

-   **Increment**: Choose any index  `i`  and replace  `s[i]`  with the next lowercase English letter. The letter after  `'z'`  is  `'a'`.
-   **Left rotate**: Move the first character of the string to the end.

Return the  **minimum**  number of operations required to make  `s`  a  palindrome.

**Example 1:**
```
Input:  s = "abc"
Output:  2
Explanation:
One optimal solution:
-   Left rotate the string:  `"abc" -> "bca"`.
-   Increment  `'a'`  to  `'b'`:  `"bca" -> "bcb"`.
-   `"bcb"`  is a palindrome. Thus, the answer is 2.
```

**Example 2:**
```
Input:  s = "yb"
Output:  3
Explanation:
-   Increment the first character three times:  `"yb" -> "zb" -> "ab" -> "bb"`.
-   `"bb"`  is a palindrome. Thus, the answer is 3.
```

**Constraints:**

-   `2 <= s.length <= 2000`
-   `s`  consists only of lowercase English letters.


### Python
```py
class Solution:
    def minOperations(self, s: str) -> int:
        n = len(s)
        mid = n // 2
        result = math.inf
        for i in range(n):
            count = i
            for j in range(mid):
                asc = abs(ord(s[(i + j) % n]) - ord(s[i - j - 1]))
                count += min(asc, 26 - asc)
            result = min(result, count)
        return result
```


### Go
```go
func minOperations(s string) int {
    n := len(s)
	mid := n / 2
	result := math.MaxInt
	for i := 0; i < n; i++ {
		count := i
		for j := 0; j < mid; j++ {
			leftIdx := (i - j - 1 + n) % n
			rightIdx := (i + j) % n
			asc := int(s[rightIdx]) - int(s[leftIdx])
			if asc < 0 {
				asc = -asc
			}
			dist := asc
			if 26-asc < dist {
				dist = 26 - asc
			}
			count += dist
		}
        result = min(result, count)
	}
	return result
}
```


### C#
```c#
public class Solution {
    public int MinOperations(string s) {
        int n = s.Length;
        int mid = n / 2;
        int result = int.MaxValue;
        for (int i = 0; i < n; i++) {
            int count = i;
            for (int j = 0; j < mid; j++) {
                int leftIdx = (i - j - 1 + n) % n;
                int rightIdx = (i + j) % n;
                int asc = Math.Abs(s[rightIdx] - s[leftIdx]);
                count += Math.Min(asc, 26 - asc);
            }
            result = Math.Min(result, count);
        }
        return result;
    }
}
```
