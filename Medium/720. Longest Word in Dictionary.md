Given an array of strings  `words`  representing an English Dictionary, return  _the longest word in_  `words`  _that can be built one character at a time by other words in_  `words`.

If there is more than one possible answer, return the longest word with the smallest lexicographical order. If there is no answer, return the empty string.

Note that the word should be built from left to right with each additional character being added to the end of a previous word.

**Example 1:**
```
Input: words = ["w","wo","wor","worl","world"]
Output: "world"
Explanation: The word "world" can be built one character at a time by "w", "wo", "wor", and "worl".
```

**Example 2:**
```
Input: words = ["a","banana","app","appl","ap","apply","apple"]
Output: "apple"
Explanation: Both "apply" and "apple" can be built from other words in the dictionary. However, "apple" is lexicographically smaller than "apply".
```

**Constraints:**

-   `1 <= words.length <= 1000`
-   `1 <= words[i].length <= 30`
-   `words[i]`  consists of lowercase English letters.


### Python
```py
class Solution:
    def longestWord(self, words: List[str]) -> str:
        visited = set(words)
        result = ""
        for word in words:
            string = ""
            for w in word:
                string += w
                if string not in visited:
                    break
            else:
                if len(word) > len(result):
                    result = word
                elif len(word) == len(result):
                    result = min(result, word)
        return result

```

### Go
```go
func longestWord(words []string) string {
    visited := make(map[string]struct{})
	result := ""
	for _, word := range words {
		visited[word] = struct{}{}
	}
	for _, word := range words {
		isValid := true
		for i := 1; i < len(word); i++ {
			if _, ok := visited[word[:i]]; !ok {
				isValid = false
				break
			}
		}
		if isValid {
			if len(word) > len(result) {
				result = word
			} else if len(word) == len(result) {
				result = min(result, word)
			}
		}
	}
    return result
}
```

### C#
```c#
public class Solution {
    public string LongestWord(string[] words) {
        HashSet<string> visited = new (words);
        string result = "";
        foreach (string word in words) {
            bool isValid = true;
            for (int i = 1; i < word.Length; i++) {
                if (!visited.Contains(word[..i])) {
                    isValid = false;
                    break;
                }
            }
            if (isValid) {
                if (word.Length > result.Length) {
                    result = word;
                }
                else if (word.Length == result.Length) {
                    result = String.CompareOrdinal(word, result) < 0 ? word : result;
                }
            }
        }
        return result;
    }
}
```
